# Zombie DJ School

Builder Network Community Challenge #1: Teach Me Something Scary.

**The scary concept:** DJing. Beat matching, bass swaps and phrase timing sound intimidating. Zombie DJ School makes them friendly. Three cute zombie coaches walk you through five short lessons, and every lesson you finish brings more zombies back to an empty dance floor.

## What you learn
1. Find the beat: tap along with the kick drum (124 BPM)
2. Match the tempo: slide deck B from 128 down to exactly 124 BPM
3. Line up the beats: nudge deck B until the two kicks sound like one
4. Swap the bass: cut one deck's low end so the mix stays clean
5. Land on the phrase: launch deck B on beat 1 of a 4 bar phrase, then crossfade

Every control changes the real audio. Matching tempo alone does not line the beats up. You cannot fail: each lesson has hints, a Show me demo and a Help me button. Free Mix unlocks at the end, with three songs per deck.

## Play it
Open `index.html` in a browser. Tap the start button first, since browsers only allow sound after a tap. Best on a phone held sideways, with headphones.

## How it is built
- One self-contained HTML file, no build step, no audio files
- All music is synthesized live with the Web Audio API (original tracks in A, D and E minor)
- Zombies, dance floor and effects are drawn on canvas
- Settings for music volume, reduced motion and bigger beat guides
